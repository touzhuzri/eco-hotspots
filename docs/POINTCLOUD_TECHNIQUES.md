# 三维点云叙事 — 技术思路手册

> 不绑定具体仓库。只回答：**想出现某种现象，该用什么技术。**  
> 适用：星系、建筑、生物、文字/诗句、数据星座等「空间点云」作品。

---

## 一、总原则

| 目标 | 技术选择 |
|------|----------|
| 一眼看出形体 | **密度场**定剪影，不是先建网格 |
| 海量条目仍流畅 | 拒绝采样 + Points + 距离 LOD，不要每条一个 Mesh |
| 远看是风景，近看是数据 | 同一套点：远景当「形」，近景当「星/字」 |
| 交互可预期 | 屏幕空间拾取 + 迟滞阈值；动画坐标与拾取坐标必须一致 |

技术栈通常只需：

```text
静态页 + three.js（Points + ShaderMaterial）+ 纯 JS 数据 + 无后端
```

---

## 二、现象 → 技术

### 1. 「点组成的立体物」如何成型

**现象：** 远看是树/星系/楼，近看是很多小点。

**技术：**
1. 写一个**密度函数** `ρ(x,y,z)`：内部≈1，外部=0，边界连续  
2. 在包围盒里**随机撒点**，以概率 `ρ` 接受（拒绝采样）  
3. 点太密/太疏 → 调 `ρ` 或每点接受概率，不要先调点大小  

**不要：** 用硬边界 `if outside box: clamp` 做造型 → 会出现削平、切面。  
**要：** 让 `ρ` 在轮廓上**平滑到 0**（轮廓 = 等值面）。

---

### 2. 「圆润顶 / 弧线剪影」vs「削平」

| 想要 | 做法 |
|------|------|
| 弧顶 | 高度方向用抛物面：允许高度 ∝ `1 - (r/R)²`，密度在顶上 ∝ `1-t²` |
| 削平（避免） | 统一 `y_max` 硬夹 → 平台 |
| 凹凸自然 | 在有效半径上叠多频正弦/值噪声，扰动包络 |

---

### 3. 「缩小一团白、放大又糊」

**现象：** 加法混合 + 固定点径，远景点全叠在一起。

**技术：**
- 混合：`AdditiveBlending` 时，**亮度必须随距离下降**（自定义 shader 里做，不要指望 Fog）  
- 点径：`gl_PointSize ≈ size / viewZ`，再 **clamp**  
  - 近：上限更小、边缘更硬 → 锐  
  - 远：略软盘、压 alpha → 不糊成白斑  
- 远景再乘一个全局 `dim(vFar)`  

**一旋钮一属性：** 体积、抖动、点径分开调，禁止混在一个参数里来回拧。

---

### 4. 「星星眨眼睛」

顶点里用 **seed 驱动多正弦 + 偶发尖峰**：

```text
phase = seed * 2π
tw = slow呼吸 * (0.8 + 0.2*fast) + pow(max(0,sin(...)), 12) * spike
```

片元用 `tw` 调亮度与 alpha。每颗相位/频率不同，避免整树同步闪。

---

### 5. 「生长入场」

**现象：** 土→干→冠 分批出现，而不是整树闪出。

**技术：**
- 每点属性 `aReveal ∈ [0,1]`（按层、高度、半径算出场顺序）  
- 全局 `uReveal` 随时间 0→1  
- `visible = smoothstep(aReveal-ε, aReveal+ε, uReveal)`  
- size/alpha 乘 `visible`  

**要点：**
- 同一高度加**方位/半径微扰**，否则像水平刀切  
- 顶部 `aReveal` 分散开，避免最后一帧全亮  
- 总时长 4–6s；再长要给进度或可跳过  

---

### 6. 「点得中」——拾取

**现象：** 看得见点不中；细线点不到。

**技术：**
- 拾取用**屏幕投影** + 点到线段/点的距离，不用 three 的 Raycast 扫 20 万点  
- **性能：** 远景只扫少量「精选点」；近景再全扫  
- **命中半径**随深度变，触控设备略放大  
- **动画沉浮必须与拾取用同一坐标**，或动画位移=0  

**线与点抢点击：**
- 有连线时：**线优先**，星只认「贴核」（约 12px）  
- 线命中半径 = **两端屏幕距离的一半**（自适应，短线易脱、长线更粘）  
- 迟滞：掠过要更近才吸上；吸上后更远才断开  

---

### 7. 「连线」表示关系

**技术：**
- 按 **父键** 归并（同一来源/作者/诗篇/建筑）  
- 用 `LineSegments` 或 fat line（`LineSegments2`）  
- 基础线压暗 + 类群色微差；悬停再提亮  

**磁吸悬停（加分项）：**
- 吸上后：线弯向指针（在**相机平面**内拉，不要往屏幕内外拉）  
- 保持判定对**弯曲线**采样  
- 吸上锁定该线；松手弹性回弹  
- 名牌可点 = 与点线同一选中逻辑  

---

### 8. 「选中后飞近 + 详情」

**技术：**
- 状态只存 `selectedId`（单一数据源）  
- 订阅里**一次**完成：飞近、连线、高亮、详情  
- 点击路径不要和订阅各扫一遍全量点  

飞近：在当前视线方向偏移一点停机位，避免绕到背面。

---

### 9. 「相机不晕」

| 现象 | 技术 |
|------|------|
| 拖拽甩飞 | 阻尼：`k = 1 - pow(base, dt)`；位置与注视点**同速率**插值 |
| WASD 像转视角 | 只平移注视点；不要在拖拽中途切第一人称 |
| 缩放有穿越感 | 滚轮**乘法**缩放（×1.12 / ×0.89），不是加减 |
| 总览太小 | 调最大距离（形体在画面里约 1/3 高），不是点径 ×3 |
| 第一人称 | 显式开关 + Pointer Lock；默认环绕更稳 |

---

### 10. 「检索 / 详情」

- 大 JSON 流式下载 + `Content-Length` 进度  
- 检索防抖 ~200ms；海量库只出 Top N，精选优先  
- 详情用本地字段拼卡片；外链公开库用 InChIKey/DOI 等稳定键  

---

### 11. 「多分辨率 / 手机」

- `100dvh` 全屏  
- 断点：大屏加宽详情；小横屏压字号与边距  
- 竖屏全屏提示横屏；可尝试 `screen.orientation.lock('landscape')`  
- 取景可用 `camera.setViewOffset` 为侧栏留空

## 三、换内容类型时改什么

| 内容 | 场/骨架 | 层 | 连线父键 |
|------|---------|----|----------|
| 天然产物/生物 | 树冠椭球+管状干 | 冠/干/根/土 | 同源生物 |
| 星系 | 旋臂对数螺线+核球 | 核/臂/晕 | 同星团/同类型 |
| 建筑 | 盒体 SDF 并集 | 基/柱/梁/幕墙 | 同楼层/同功能 |
| 诗句 | 字高程=行序，水平=句内位置 | 篇/联/字 | 同篇/同韵 |
| 通用 | 任意 `ρ(x,y,z)` | 自定 | 业务主键 |

**交互层可整段复用：** 拾取、连线、迟滞磁吸、入场 `aReveal`、检索框、详情卡。

---

## 四、最小可行顺序（从零）

1. 定 `ρ` 与层 → 采样 1e4 点，确认剪影  
2. 上 shader：软点 + 远近 LOD + 闪烁  
3. 环绕相机 + 乘法缩放 + 阻尼  
4. 屏幕拾取 + 飞近 + 详情  
5. 连线 + 线优先拾取  
6. 入场生长  
7. 检索、进度条、横屏、部署  

每步可单独验收，避免一次拧所有旋钮。

---

## 五、性能与体验红线

- 加法混合必须距离压暗  
- 产物/可点层不要做大幅顶点位移  
- 状态变更不要每帧全量重算颜色  
- 入场与加载都要有「还在动」的反馈  
- 一属性一旋钮  

---

## 六、一句话

**剪影用密度场，数据用拒绝采样挂点，远近用 shader 管亮度与锐度，交互用屏幕空间+迟滞，动画坐标与拾取坐标必须同一套。**
